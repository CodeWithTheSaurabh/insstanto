# Insstanto - Home Services Platform

Insstanto is a modern, responsive web application for booking home services. It provides a user-friendly interface for browsing and booking various home services like cleaning, plumbing, electrical work, salon services, and more.

## Features

- Responsive design that works on both desktop and mobile devices
- Dark mode support
- Interactive service categories
- Trending services section with standardized card layout
- Auto-typing text animations
- Loading screen with developer credit
- Mobile-optimized navigation with bottom menu

## Technologies Used

- React.js
- Vite
- CSS3 with responsive design
- React Icons
- React Slick for carousels

## Live Demo

Visit the live website: [Insstanto](https://codewithTheSaurabh.github.io/insstanto/)

## Development

To run this project locally:

```bash
cd insstanto-frontend
npm install
npm run dev
```
